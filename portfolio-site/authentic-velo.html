بخشی واقعی از بک‌اند Velo

اپ اصلی Velo با Kotlin و Android ساخته شده و داخل مرورگر اجرا نمی‌شود. اینجا خود فایل backend/app/security.py را با موتور Python WebAssembly اجرا می‌کنید: ساخت توکن امضاشده، بررسی هویت و رد کردن توکن دست‌کاری‌شده.

آزمایش ماژول امنیتی

در حال دانلود موتور Python در مرورگر…
این ماژول همان کد واقعی پروژه است و بدون سرور، داده کاربر یا کلید تولید اجرا می‌شود. کلید تست فقط برای این محیط ساخته می‌شود؛ VPN واقعی روشن نمی‌شود. دانلود اولیه موتور Python ممکن است کمی طول بکشد.
